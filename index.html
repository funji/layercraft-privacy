Privacy Policy

Effective November 3, 2026 · Layercraft — Layered TIFF & PSD · Figma plugin
Privacy at a glance

Layercraft converts your designs on your device. The plugin does not upload your designs to a developer-operated server and does not include analytics, advertising, tracking, or accounts.

Layercraft runs as a Figma desktop plugin and converts the frames, groups or layers you choose into Photoshop-compatible files on your device.

Data we process

When you run an export or request a preview, the plugin reads selected design nodes, including names, layer structure, images, fonts, dimensions and relevant visual attributes. The plugin may also inspect frames on the current page when you choose that scope. This information is processed in the local plugin environment to create the exported TIFF/PSD files and on-screen notices.

Data we collect or transmit

The plugin does not send design files, personal information, documents or diagnostics to a developer-operated server. It has no analytics, advertising, telemetry or sign-in mechanism, and declares no network access in its Figma plugin manifest. Your interactions with the Figma platform remain subject to Figma's own terms and privacy policy. The plugin does not transmit files to the developer.

Storage

Export settings, manual font mappings and any optional font-list JSON you choose to import are saved through Figma's client-side plugin storage. Only the export documents (TIFF/PSD, or a ZIP containing them) are downloaded to locations you choose on your device. Conversion diagnostics remain within the local plugin session. The developer does not remotely store them. You can clear an imported font list in advanced options. You can remove locally saved plugin preferences using Figma's available controls for plugin data (where supported) or by uninstalling/reinstalling according to Figma's behavior.

Optional Photoshop font list

The optional helper script reads installed font names from your local Photoshop application and saves a JSON file in the location you choose. It does not copy font files, modify documents or upload data. It is not needed for ordinary exports.

Third-party software

Layercraft includes original proprietary code and third-party open-source libraries whose licenses are supplied with the release. Layercraft does not use third-party conversion services.
